## Коротко

Два движка. Один бенчмарк. Битва парадигм.

| движок                 | что это                                                        |
|------------------------|-----------------------------------------------------------------|
| `von_neumann`          | классический цикл fetch-decode-execute над памятью данных в 256 ячеек |
| `broth`                | 3D-решётка вокселей, которые преобразуют друг друга локально — без PC, без ветвлений, без инструкций |

```console
$ tensor-broth bench --cube 24 --steps 60 --vm-steps 200000
tensor-broth | python 3.12.15 | torch 2.14.1+cpu
| backend | device | VM Mops/sec | broth GOPS (effective) | broth activity |
|:--------|:-------|------------:|----------------------:|---------------:|
| vm      | cpu    |        0.88 |                     - |              - |
| torch   | cpu    |        0.88 |       1.15            |         0.2682 |
```

VM протаскивает ~1 миллион *инструкций* в секунду через питоновский цикл
выборки-декодирования. «Бульон» протаскивает ~10⁹ *взаимодействий
воксель×отвод* в секунду через один слитый `conv3d` — потому что
структура данных **и есть** программа, а железо, которое она хочет, — GPU.

## Идея

Машина фон Неймана всю жизнь таскает данные между памятью и АЛУ: выборка,
декодирование, исполнение, повтор. «Бульон» отменяет саму поездку.
Состояние живёт в 3D-тензоре `(value, affinity, gradient) × D × H × W`,
а один такт — это:

```
space ← tanh(space + dt · conv3d(space, kernel))
```

Каждый воксель читает свою окрестность 3×3×3 и обновляется. Вот и вся
система команд. Сложность такта — `O(объём)`, но он *полностью
data-параллелен*: один и тот же текст программы масштабируется от CPU-
тензора к CUDA-тензору и (концептуально) к оптической или мемристивной
решётке — без единого изменения кода.

Это мышление субстрата из мира клеточных автоматов, непрерывных reservoir
computers и «физических сопроцессоров»: если данные пространственные —
может, и *компьютер* должен быть пространственным.

## Три канала

| канал   | роль                                                                    |
|---------|--------------------------------------------------------------------------|
| 0       | value — собственно сигнал, живущий в бульоне                             |
| 1       | affinity — локальная маска, модулирующая силу связи с соседями           |
| 2       | shift gradient — направленное смещение, бегущее по решётке               |

Ядро взаимодействия — случайный тензор 3×3×3×3×3 (с сидом, поэтому прогоны
воспроизводимы). Поменяйте его — получите другую «физику».

## Установка

```bash
pip install tensor-broth            # ядро на numpy
pip install "tensor-broth[torch]"   # + бэкенд PyTorch (CPU или CUDA)
```

Нет torch? Чистый NumPy-движок (`sliding_window_view` + `tensordot`)
реализует ту же семантику — парадигма тестируема где угодно. Честная
оговорка: NumPy-фолбэк медленнее на воксель — он существует ради
корректности и любопытства, а не ради побед в бенчмарках.

## Использование

### Python

```python
from tensor_broth import make_engine, run_von_neumann_vm

# старый мир
vm = run_von_neumann_vm(n_steps=1_000_000)
print(f"VM: {vm.mops_per_sec:.2f} Mops/sec")

# бульон
engine = make_engine(backend="auto", cube_size=64)   # torch, если есть
elapsed = engine.run(1000)
print(f"broth: {engine.voxel_ops(1000) / elapsed / 1e9:.2f} GOPS effective")
print(f"activity: {engine.activity():.4f}")
```

### CLI

```
tensor-broth bench --cube 64 --steps 1000 --backend auto [--json]
tensor-broth sim   --cube 32 --steps 200
```

`bench` гоняет обе парадигмы и печатает (или отдаёт в JSON) сравнение.
`sim` запускает только бульон и сообщает финальную активность и пропускную
способность.

## Куда это можно развивать

- Обучать ядро («фермент»), а не брать случайное — градиентный спуск по
  весам `conv3d` это просто 3D-CNN с необычной семантикой.
- Разреженные решётки / октодеревья: большая часть объёма скучна; пусть
  бульон работает только там, где интересно.
- Альтернативная нелинейность — сегодня `tanh`, но пороги клеточного
  автомата (`sign`, `round`) сделали бы его полностью без-float. См.
  наш проект-сателлит **timelock-ca** — там именно эта одержимость.
- Многоканальная реакция-диффузия (Gray-Scott в этом фреймворке —
  строк 10).
